# Icônes d’interface

Ces douze SVG proviennent de [Lucide](https://lucide.dev/) et ont été
synchronisés depuis `lucide-icons/lucide`, branche `main`, le 17 août 2026.
Ils sont rasterisés en PNG R8 @2× pendant la construction ; l’application ne
parse aucun SVG à l’exécution.
